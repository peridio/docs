---
title: 'Connect: 2026.03'
description: 'Avocado Connect highlights for March 2026 — fleet management, tag-based deployments, and CLI auth.'
---

- **Fleet page overhaul** — device tags, multi-select filters with global scope, and a device activity chart with reactive stats.
- **Tag-based deployments** — target a deployment by device tag, with tags auto-assigned through claim tokens.
- **Claim-token provisioning** — a per-project Provisioning tab to manage claim tokens (now defaulting to a 1-year expiration).
- **Deployment controls** — complete or cancel a deployment straight from its detail page.
- **Device tunnels** — copy the SSH command for an established tunnel, with tunnels gated on device capability.
- **Auth** — browser-based CLI login and org-scoped API tokens.
