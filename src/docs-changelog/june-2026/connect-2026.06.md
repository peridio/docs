- **Self-serve billing** — the Startup tier (per-seat Stripe checkout with in-app seat updates) and a flat-rate Teams tier with self-serve seat and device add-ons.
- **Deployments rollout tab** — per-device rollout status with a pre-activation preview, in a sortable table.
- **Org API-key management** — a Settings → API Keys tab.
- **CLI org selection** — pick an org explicitly at login.
- **Tunnel limit requests** — Teams orgs can request tunnel-limit increases.
