Released on 19 November. The avocado-vm is the Linux VM that `avocado vm` and
Avocado Desktop build in. Update it with `avocado vm update`, or from
**Settings → Updates** in Avocado Desktop on macOS.

## Changed

- **The image moves to the latest 2026/next snapshot.** The kernel is
  unchanged.
- **The image ships `avocado-ext-connect` 0.3.0.**

A VM used only for builds sees no other change. The rest of this release is
for hub features that are not documented yet.
