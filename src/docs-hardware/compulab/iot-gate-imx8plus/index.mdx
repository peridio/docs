## Overview

The CompuLab IOT-GATE-iMX8PLUS is a fanless industrial IoT gateway built as a
carrier board for the [CompuLab UCM-i.MX8M-Plus](/hardware/compulab/ucm-imx8m-plus)
Computer-on-Module. It is not a separate Avocado build target - Avocado OS
builds the `ucm-imx8m-plus` machine, and a carrier extension selects the
gateway's own device tree and brings up its carrier-specific peripherals at
build time. For the module's own SoC, CPU, memory, and industrial
specifications, see the [UCM-i.MX8M-Plus hardware page](/hardware/compulab/ucm-imx8m-plus) -
they apply here unchanged; this page covers only what the gateway carrier
adds.

## Carrier-Specific Hardware

| Capability     | Detail                                                       |
| -------------- | ------------------------------------------------------------ |
| Cellular modem | MHI-based modem, managed via ModemManager                    |
| GNSS / GPS     | On-carrier GPS, exposed via `gpsd`                           |
| CAN bus        | Carrier CAN interface (`flexcan`)                            |
| TPM (optional) | M.2 discrete TPM 2.0 module - a real TPM, not an OP-TEE fTPM |

For full electrical, mechanical, and environmental specifications, see
CompuLab's own [IOT-GATE-iMX8PLUS product page](https://www.compulab.com/products/iot-gateways/iot-gate-imx8plus-industrial-arm-iot-gateway/).

## Getting Started

### Init, Install, & Build

Follow the [Any Supported Target](/learn/get-started/any-target)
instructions under Getting Started. The build target is `ucm-imx8m-plus`; add
the gateway carrier extension to bring up the peripherals above:

```yaml
default_target: ucm-imx8m-plus

extensions:
  avocado-bsp-iot-gate-imx8plus:
    source:
      type: package
      version: '*'

runtimes:
  dev:
    extensions:
      - avocado-bsp-iot-gate-imx8plus
```

```bash
avocado install
avocado build
```

### Provision

The gateway is programmed through the on-module eMMC over USB, with the `uuu-emmc` profile. We have run this path end to end on the IOT-GATE-iMX8PLUS on the 2026 release.

1. Put the gateway in **USB serial download** mode, and connect its USB OTG port to your host. CompuLab's [IOT-GATE-iMX8PLUS documentation](https://www.compulab.com/products/iot-gateways/iot-gate-imx8plus-industrial-arm-iot-gateway/) covers the boot-mode selection and which port is the OTG port.
2. Build and provision:

   ```bash title="Host machine"
   avocado build
   avocado provision dev --profile uuu-emmc
   ```

3. When programming completes, return the gateway to eMMC boot and power-cycle it. On first boot, the carrier extension switches the boot device tree to `iot-gate-imx8plus.dtb`. That takes effect from the next reboot.

The `sd` profile and the module-level details (console, device-tree overlays) are on the [UCM-i.MX8M-Plus page](/hardware/compulab/ucm-imx8m-plus#getting-started).
