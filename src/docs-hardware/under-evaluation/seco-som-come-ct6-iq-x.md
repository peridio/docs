# SECO SOM-COMe-CT6-Dragonwing-IQ-X

COM Express Type 6 Compact module with a Qualcomm Dragonwing IQ-X Series SoC

**Qualcomm Dragonwing IQ-X** | **Up to 45 TOPS** | **Up to 64GB LPDDR5** | **-40 to 85°C**

<a href="https://developer.seco.com/hardware/product/computer-on-modules/com-express-modules/som-come-ct6-dragonwing-iq-x-f31/" target="_blank" rel="noopener noreferrer">View on the SECO Developer Center</a>

## Overview

The SECO SOM-COMe-CT6-Dragonwing-IQ-X is a COM Express 3.1 Type 6 Compact module. It uses a Qualcomm Dragonwing IQ-X Series SoC with 8 or 12 Oryon CPU cores and a Hexagon NPU. SECO lists industrial PCs, advanced HMIs, and AI-driven automation as target applications.

Avocado OS support for this module is under evaluation.
