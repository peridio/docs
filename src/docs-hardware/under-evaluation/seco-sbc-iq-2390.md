# SECO SBC-Dragonwing-IQ-2390

Compact single-board computer with a Qualcomm Dragonwing IQ-2390 SoC

**Qualcomm Dragonwing IQ-2390** | **Up to 1.1 TOPS** | **2GB or 4GB RAM** | **47 x 114 mm**

<a href="https://developer.seco.com/hardware/product/single-board-computers/other-form-factors/sbc-dragonwing-iq-2390" target="_blank" rel="noopener noreferrer">View on the SECO Developer Center</a>

## Overview

The SECO SBC-Dragonwing-IQ-2390 is a compact single-board computer with a Qualcomm Dragonwing IQ-2390 SoC. SECO lists custom controllers, gateways, and user interfaces as target applications. At this time, the board is in the SECO Early Access Program.

Avocado OS support for this board is under evaluation.
