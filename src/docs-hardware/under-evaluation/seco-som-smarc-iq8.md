# SECO SOM-SMARC-Dragonwing-IQ8

SMARC module with a Qualcomm Dragonwing IQ-8275 SoC

**Qualcomm Dragonwing IQ-8275** | **Up to 40 TOPS** | **Up to 32GB LPDDR5/5X** | **82 x 50 mm**

<a href="https://developer.seco.com/hardware/product/computer-on-modules/smarc-modules/som-smarc-iq8-f86/" target="_blank" rel="noopener noreferrer">View on the SECO Developer Center</a>

## Overview

The SECO SOM-SMARC-Dragonwing-IQ8 is a SMARC module with a Qualcomm Dragonwing IQ-8275 (QCS8275) SoC and a Hexagon NPU. SECO lists robotics, industrial vision, and machine control as target applications. At this time, SECO ships engineering samples to selected customers.

Avocado OS support for this module is under evaluation.
