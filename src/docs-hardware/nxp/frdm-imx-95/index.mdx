## Overview

The FRDM-i.MX 95 is NXP's Freedom development board for the i.MX 95 applications
processor family, integrating six Cortex-A55 cores, Cortex-M7 and M33
safety-domain cores, an Arm Mali GPU, a 2.0 TOPS eIQ Neutron NPU, 4K VPU, and
ISP. It provides a comprehensive evaluation platform with Gigabit Ethernet, USB
3, PCIe Gen3, and an M.2 slot for Ara-series AI accelerator expansion. Paired
with Avocado OS and Avocado Connect, it gains production-ready enterprise Linux,
atomic OTA updates, and fleet management.

## Use Cases

### Safety-Critical Edge AI

Prototype ASIL-rated devices that pair the Cortex-A55 application cores with the
M7/M33 safety domain and the eIQ Neutron NPU.

### Vision-Enabled Robotics

Combine the NPU and integrated ISP for on-device vision, expandable with an
Ara-series M.2 accelerator.

### Industrial HMI and Gateways

Gigabit networking, PCIe Gen3, and Wi-Fi 6 for connected industrial edge
deployments.

## Getting Started

### Init, Install, & Build

Follow the [Any Supported Target](/developer-reference/getting-started/any-target)
instructions under Getting Started to begin. This target is `imx95-frdm`. The
provisioning specifics are below.

### Provision

Build the project and execute the provisioning procedure. This will build the
system image and flash it to your target hardware.

:::note Provisioning on a Linux host
If your Linux desktop auto-mounts removable media, disable it first — see
[Linux Auto-Mounting](/developer-reference/linux-auto-mounting).
:::

```bash title="Host machine"
avocado build
avocado provision -r dev --profile sd
```

### Run

After provisioning completes, insert the SD card into your target device and
power it on. The device will boot with the provisioned system. The `root` user
is passwordless in the `dev` runtime used by this guide.
