## Overview

The `intel-x86-64-v4` target builds all packages for the x86-64-v4
microarchitecture level. This level requires AVX-512 (F, VL, BW, CD, and DQ).
Software that uses wide vector instructions, such as CPU inference and data
compression, can run faster than on the v3 target.

The target is `intel-x86-64-v4`. Support is in progress on the **2026** release.

:::caution

Do not use this target on CPUs without full AVX-512. The image does not run
on them. This includes the Intel hybrid client CPUs from Alder Lake onward,
Panther Lake included, and the Intel Xeon 6 E-core processors (Sierra Forest
and Clearwater Forest). Use [x86-64-v3](/hardware/intel/x86-64-v3) for these
CPUs.

:::

## Specifications

| Specification | Value                                   | Notes                                                 |
| ------------- | --------------------------------------- | ----------------------------------------------------- |
| Architecture  | x86-64-v4                               | AVX-512 F, VL, BW, CD, DQ required                    |
| Intel client  | Ice Lake, Tiger Lake, Rocket Lake       | Alder Lake and newer are not supported                |
| Intel Xeon    | Xeon Scalable P-core, Skylake-SP onward | Sierra Forest and Clearwater Forest are not supported |
| AMD           | Zen 4 and Zen 5                         | Ryzen 7000 and 9000, EPYC Genoa and Turin             |
| Boot          | UEFI                                    | Legacy BIOS is not supported                          |
| Security      | TPM 2.0                                 | Discrete TPM or Intel PTT                             |
| GPU           | NVIDIA discrete GPU driver in the feed  | The modules do not load without a GPU                 |
| Storage       | NVMe, SATA, USB                         | Standard block devices                                |

## x86-64-v4, v3, or v2

Choose **x86-64-v4** when every device in the fleet has a CPU with full AVX-512.
Choose [x86-64-v3](/hardware/intel/x86-64-v3) for AVX2 CPUs from Intel Haswell
and AMD Excavator onward, which includes the hybrid client CPUs. Choose
[x86-64-v2](/hardware/intel/x86-64-v2) for older processors or mixed fleets.

## Getting Started

### Init, Install, & Build

Follow the [Any Supported Target](/learn/get-started/any-target#intel-x86-64-v4)
instructions under Getting Started. This target is `intel-x86-64-v4`.

```bash title="Host machine"
avocado init --target intel-x86-64-v4 intel-x86-64-v4
cd intel-x86-64-v4
avocado install
avocado build
```

### Provision

Write the image to a USB drive:

```bash title="Host machine"
avocado provision dev --profile usb
```

### Run

Put the USB drive in the device and boot from USB through UEFI. The `root`
user is passwordless in the `dev` runtime used by this guide.
