Developer Reference is where you look things up once you're building with Avocado. It holds task guides for working with Avocado OS, and the reference docs for each Avocado tool and API.

:::tip New to Avocado?

Start with [Learn](/learn). It takes you from installing the CLI to running your code on a device, step by step. Come back here when you need detail on a specific topic.

:::
