# Tutorials

Each tutorial starts from a reference project, walks through every file that matters, and ends with a change you make and rebuild. They run on QEMU, so you need no hardware.

New to Avocado OS? Read [Core Concepts](/avocado-os/core-concepts) first. It explains `avocado.yaml`, runtimes, extensions, overlays, systemd services, and lifecycle hooks, which every tutorial builds on.
