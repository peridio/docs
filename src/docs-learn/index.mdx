# Start here

Learn is the guided path through Avocado OS and Avocado Connect. Build a first bootable image, then work through the missions in order: each one builds on the last. Your progress is saved in this browser.

<Steps eyebrow="Ready in minutes, not days" title="How Learn works">

<Step title="Get started">

[Install the CLI and boot your first image](/learn/get-started) on QEMU or a supported board.

</Step>

<Step title="Complete the missions">

Ship an OTA update, reach an app remotely, then choose your hardware path.

</Step>

<Step title="Go deeper">

Use the [tutorials](/learn/tutorials) for focused, single-topic walkthroughs.

</Step>

</Steps>
